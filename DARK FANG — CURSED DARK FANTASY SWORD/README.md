# DARK FANG — CURSED DARK FANTASY SWORD

A dark-fantasy sword 3D asset project created for Blender 5.2.2 LTS, with a production-oriented pipeline covering blockout, hard-surface detailing, high-poly refinement, damage/wear, PBR materials, UVs, 4K texture maps, game-ready LODs, presentation, and multi-format export.
